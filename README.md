玫瑰使用本仓库的 **Settings → Pages → main → / (root)** 发布。页面只显示礼物内容，不显示统计。

管理页使用部署者已有的 ChatGPT 账号登录，其他账号不能查看。可查看累计打开、累计点击、最近200条北京时间明细，以及导出全部CSV。不要将管理页作为玫瑰链接发给访客。

点击由独立公网接收接口保存到持久数据库，关掉自己的电脑也能记录。数据不写入这个公开仓库，不依赖访客或自己的本地浏览器保存。建议定期导出CSV备份。

打开次数包括刷新；点击统计玫瑰轻触和控制按钮，拖动不计点击。统计不是独立访客人数，不识别具体是谁；断网、脚本拦截和设备时钟误差可能影响记录。

上线联通验证写入了1次打开和1次点亮点击；它们是最初两条记录，事件ID分别为00000000-0000-4000-8000-000000000001和00000000-0000-4000-8000-000000000002。

网页使用本地 three.min.js，无需构建。analytics-config.js 只保存公开接收地址，绝不能加入任何密码或令牌。
